\begin{abstract}
We present the B16 scanner module: the detection layer of a structure-weighted
outbreak mutation early-warning engine, delivered as a clean, reusable,
fully reproducible module. The module scans weekly public genome-submission
aggregates and flags mutations whose growth slope is weighted by structural
criticality derived entirely from published experimental data (antibody--spike
and ACE2--spike contact geometry and SARS-CoV-1 conservation). All gates were
locked before any output was computed. On the pinned LAPIS snapshot
(dataVersion 1790179197) the module reproduces the committed reference
validation outputs with zero mismatches across all 21 monthly frozen scans,
agrees with the independently sealed B17 structural scorer on 22/22 flagged
spike substitutions, and ships a command-line tool with hardened input
validation. Honest negatives are preserved: two pre-registered controls
(S:D614G, S:L452R) are not flagged, matching the reference exactly.
\end{abstract}

\section{Problem and prior art}
Genomic surveillance needs early warning: flag concerning mutations before they
dominate. Four published systems bound the space. VirusWarn ranks variants by
mutation-burden keyword rules; FEVER estimates empirical mutational risk from
lineage outcomes; CoVerage scores antigenic impact with curated literature
weights plus epidemiological dynamics; Nextstrain tracks phylogeny descriptively.
None ranks flags by structural criticality derived from validated experimental
geometry with a pre-registered frozen-window catch test (prior-art verdict:
CROWDED, angle survives, adopted verbatim from the B18 validation slice).
The engine's reference implementation was validated retrospectively in the B18
slice (S:N501Y flagged 48 days before literature recognition). This slice
delivers the scanner itself as a standalone module and proves it reproduces the
reference behavior exactly.

\section{Data and discipline}
All scan inputs come from the LAPIS open v2 instance (cov-spectrum),
snapshot 1790179197, byte-locked on 2026-09-23 (weekly amino-acid mutation
scans, daily sequence totals, 2019-12-30 to 2021-10-04). The snapshot's
staleness is by design: this slice targets the locked estimand (exact
reproduction of reference scan behavior on pinned bytes), not live
surveillance. Structural ground data are byte-locked PDB complexes
(6M0J, 6WPT, 6XDG, 7C2L; extension 6M17, 6XCM, 7C01, 6W41 in the B17 slice)
and the SARS-CoV-2/SARS-CoV-1 spike alignment. Gates were locked in
\texttt{scanner/GATES\_LOCKED.md} before any output; one pre-outcome amendment
(\texttt{GATES\_AMENDED\_1.md}) fixed the reference definition to the amended
pipeline actually used by the committed results.

\section{Module contract}
Weekly bins (Monday + 7d). A mutation is a candidate at freeze $F$ if, using
only weeks ending $\le F$: count in the last 4 weeks $\ge 20$, proportion
$\ge 0.001$, and the slope $g$ of $\log_{10}((c+0.5)/(t+1))$ over the last 6
visible weeks (observed weeks only, $\ge 4$ of 6) is positive. Alert score
$A = g\,(0.5 + S)$, where the structural-criticality weight for spike is
$S = 0.35\,[\mathrm{epitope}] + 0.25\,[\mathrm{ACE2}] + 0.15\,[\mathrm{cleavage}]
+ 0.15\,[\mathrm{domain}] + 0.10\,[\mathrm{conserved}]$;
non-spike mutations get $S=0$ (documented limitation). Alerts are selected by
the frozen per-scan robust z-score rule ($Z=6.6$ on $A$; comparator $Z_G=4.8$
on $g$ alone). All constants are the committed frozen ones; nothing was retuned.

\section{Results (verbatim, run once)}
\paragraph{S1 reproduce-detection: PASS.} All 21 month-end frozen scans
(2020-01-31 through 2021-09-30) reproduce the committed reference outputs with
zero mismatches in weighted alert lists and growth-only alert counts
(\texttt{scanner/results/reproduce\_gate.json}).
\paragraph{S2 scorer agreement: PASS.} The module's structural scores equal the
independently sealed B17 scorer's base scores on 22/22 flagged spike
substitutions. Four flagged spike deletions (S:E156-, S:F157-, S:K310-, S:Y144-)
fall outside the B17 CLI's substitution-only contract; the module scores them
with the same locked formula as the reference engine (S = 0.0, 0.0, 0.1, 0.35).
\paragraph{S3 CLI contract: PASS.} \texttt{omew\_scan.py scan --freeze}
returns frozen-scan JSON (407 candidates at 2020-10-31, alerts led by S:E484K,
$A=0.2366$); \texttt{score --mutations} passes through to the B17 scorer.
Malformed inputs (\texttt{S:501}, \texttt{:N501Y}, \texttt{n501y},
\texttt{S:N501}, non-ISO dates) are all rejected with exit code 2; the
rejections were demonstrated before the CLI was accepted.
\paragraph{S4 module self-check: PASS.} First-flag dates for the three
pre-registered controls agree with the committed catch test exactly:
S:D614G unflagged (both), S:N501Y flagged 2020-10-31 (both; 48 days before
recognition), S:L452R unflagged (both). This is agreement with the reference,
not a new validation claim.

\section{Honest negatives and limitations}
Two of three pre-registered controls are never flagged --- this is reference
behavior, preserved rather than patched, and the B18 slice documents the
estimator pivots that led here. Structural weighting covers spike only;
non-spike mutations are ranked by growth alone. The scanner scores a pinned
historical snapshot; live deployment would need a fresh data lock and a new
catch test, which this slice deliberately does not claim.

\section{The tool}
\texttt{scanner/tool/omew\_scan.py} exposes the frozen scan and the structural
scorer behind strict input validation. Together with the B17 scorer it forms
the engine's reusable front end: given a freeze date it returns ranked,
structure-weighted alerts with every constant visible.

\section{Reproduction}
\texttt{python3 scanner/code/reproduce\_gate.py} (pinned bytes under
\texttt{validation/data/}); manifests: \texttt{scanner/MANIFEST.sha256} and the
updated top-level \texttt{MANIFEST.sha256}. Category: computational biology
(CBIO). All data open; no spending, no restricted access.
